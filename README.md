# LittleLemon
Here are the main API endpoints to test the Little Lemon application:

Menu API:
/restaurant/menu/
/restaurant/menu/<id>/

Booking API (Requires Token Authentication):
/restaurant/booking/tables/

User Registration & Authentication (Djoser):
/auth/users/
/auth/users/me/
/auth/token/login/
/auth/token/logout/
